Multi-model API

Select GPT-5.5, GPT-5.6 sol or terra, and GPT-6 astra through one InferGate endpoint without changing SDK configuration.

Keep your client and endpoint fixed, and select a published identifier per request. This lets an application compare models without creating a separate SDK connection for each model.

  • gpt-5.5
  • gpt-5.6-sol
  • gpt-5.6-terra
  • gpt-6-astra

Explicit selection instead of hidden replacement

Store the chosen model alongside your request ID and output. If you implement fallback in your own application, make that decision explicit and retain both requested and returned identities. An unavailable model must not appear as a successful call to another model.

Evaluate a model switch

  • Run the same representative inputs with fixed output limits.
  • Check completion and non-empty output, then score task correctness.
  • Compare observed latency and actual usage costs.
  • Only expand rollout after verifying the required permissions and behavior.
