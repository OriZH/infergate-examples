Frequently asked questions

Which identifier should I send for GPT-5.6 Sol?

Send gpt-5.6-sol exactly. Use the same API key to check GET /v1/models before requesting this model. Display labels and family names are not replacements for the request ID.

Why can a published model be unavailable to my key?

The website describes the public catalog. Your account group, API key model restrictions and balance can affect a specific request. Inspect the actual error and authenticated list before retrying.

Is sol faster or more accurate than terra?

No comparative speed or accuracy claim is established here. Compare both variants on the same representative prompts and current rates; model suffixes are not benchmark results.

How do I verify a streamed response?

Require the completion event and useful text. Preserve the request ID and actual model identity. A connection that ends before completion is not a successful result merely because HTTP status was 200.
