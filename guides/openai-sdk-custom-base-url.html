Configure an OpenAI SDK custom base URL

Set Python base_url or Node.js baseURL to the InferGate API endpoint. Avoid doubled v1 paths, wrong credentials and app-host requests.

Use the API host

The SDK base URL is https://api.useinfergate.com/v1. Do not use the public website or application host as the SDK endpoint.

ClientOptionValue
Pythonbase_urlhttps://api.useinfergate.com/v1
Node.jsbaseURLhttps://api.useinfergate.com/v1

Avoid path and credential mistakes

  • Use an InferGate key, not a key from a different provider.
  • Include /v1 once in the base URL; the SDK appends /responses.
  • Keep secrets in environment variables or a server secret manager.
  • List available models with the same key before selecting an ID.

Minimal configurations

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["INFERGATE_API_KEY"],
    base_url="https://api.useinfergate.com/v1",
)
response = client.responses.create(
    model="gpt-5.5",
    input="Reply with one sentence about API design.",
    max_output_tokens=256,
)
print(response.output_text)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.INFERGATE_API_KEY,
  baseURL: "https://api.useinfergate.com/v1",
});
const response = await client.responses.create({
  model: "gpt-5.5",
  input: "Reply with one sentence about API design.",
  max_output_tokens: 256,
});
console.log(response.output_text);
