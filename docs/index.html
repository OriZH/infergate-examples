API documentation

Build with the InferGate API

InferGate provides OpenAI-compatible API access for teams that want one gateway for model routing, API keys, usage tracking, and credit-based consumption.

Base URL and authorization

Base URL: https://api.useinfergate.com/v1

Authorization: Bearer YOUR_INFERGATE_API_KEY

Create and manage API keys in the InferGate Dashboard.

Chat Completions

Send chat completion requests to the OpenAI-style endpoint using your InferGate API key.

curl https://api.useinfergate.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_INFERGATE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "system",
        "content": "You are a concise technical assistant."
      },
      {
        "role": "user",
        "content": "Explain unified AI API gateways in one paragraph."
      }
    ]
  }'

Models endpoint

List models currently available to your account. Model availability depends on account settings, enabled channels, upstream provider availability, and dashboard configuration.

curl https://api.useinfergate.com/v1/models \
  -H "Authorization: Bearer YOUR_INFERGATE_API_KEY"

OpenAI-style clients

InferGate is designed to work with OpenAI-style API clients by setting the API key to your InferGate key and the base URL to https://api.useinfergate.com/v1. Review your dashboard for enabled models, current pricing, usage records, and balance before production use.
