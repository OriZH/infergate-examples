Frequently asked questions

How do I get GPT-5.5 API access?

Create an InferGate account, check the wallet and model permissions, and create a server-side API key. Use the authenticated catalog before sending a small test request.

Which GPT-5.5 model IDs are available?

gpt-5.5. Availability is checked per account; the family name is not a generic routing alias.

Is there a fixed price or guaranteed free allocation?

This page makes no fixed-price or free-credit promise. Review current application pricing, account balance and any applicable credit conditions before running requests.

Can I keep my existing SDK?

The examples use the OpenAI SDK with a custom base URL and an InferGate key. Validate the endpoint and parameters your application uses instead of assuming complete feature parity.
