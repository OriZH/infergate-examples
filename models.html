Check access before sending requests

Use your own InferGate key to request the live catalog. Account permissions, key restrictions and available balance still apply. A model listed here is not a guarantee of uninterrupted upstream service.

curl --fail-with-body https://api.useinfergate.com/v1/models \
  -H "Authorization: Bearer $INFERGATE_API_KEY"

Retired model requests return model_not_available. InferGate does not silently substitute another model. Keep keys on your server and out of browser bundles.
