Prepaid API pricing

Understand InferGate prepaid API usage, current model pricing, output costs and account balance before funding an integration.

InferGate uses prepaid account credit for API requests. The application is the authoritative source for current rates and available top-up options. No purchase or payment is initiated by visiting this page.

Read the current rate before buying

View live application rates. Confirm the exact model, input and output rate, unit size, and any displayed account multiplier. Do not assume that two variants have the same price.

Estimate a workload

For a simple input/output rate, estimated cost equals input tokens divided by the published unit size times the input rate, plus output tokens divided by the unit size times the output rate. Apply any documented additional billing components. Reconcile estimates against a small real request and its usage log.

Before you add credit

  • Check your current balance and account model permissions.
  • Estimate realistic prompt lengths and output limits.
  • Read the linked refund terms before making a payment.
  • Use a small workload first; a successful HTTP connection alone does not establish a completed response.
